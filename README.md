# 校園生活50問（Campus Life Quiz）

Google Apps Script + Google Sheets + HTML 的校園生活互動問答系統。

- 前端穩定版本：V1.4.9
- 後端穩定版本：V1.4.8
- GitHub 專案名稱建議：`campus-life-quiz`

## 主要功能
- 18 班級獨立進度
- localStorage 本機保存 + Google Sheet 雲端同步
- 10×5 題目牆，最多 50 題
- 卡牌顯示本局流水號 01、02、03……
- 題目視窗保留資料庫題號
- 三種選題模式：整體亂數／題庫配額／手動選題
- 全螢幕
- 教室投影大字
- 題目／答案圖片
- 答案圖片近全畫面且不裁切
- 已答題可再次查看（預設開啟）
- 答錯題可再次作答至正確（預設關閉）
- 內建操作使用說明

## 題數規則
50 題是上限，不是固定數量。若實際可用題目少於設定題數，就以實際題數建立卡牌，不補空白、不重複抽題。

## 題庫工作表
工作表：`題庫`

|欄|名稱|
|---|---|
|A|編號|
|B|類別|
|C|題目|
|D|選項A|
|E|選項B|
|F|選項C|
|G|選項D|
|H|正確答案|
|I|答案解析|
|J|出處|
|K|答案圖片URL|
|L|題目圖片URL|
|M|啟用|

只有 M=TRUE 的題目可使用。

## 班級工作表
工作表：`班級`

A 班級代碼／B 班級名稱／C 啟用

## 遊戲進度工作表
工作表：`遊戲進度`

A 班級代碼／B 班級名稱／C 遊戲局號／D 答題紀錄JSON／E 正確／F 錯誤／G 已完成／H 最後更新
